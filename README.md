# Budget Manager

Static mobile-style budget manager built with HTML, CSS, Vanilla JavaScript, and Ionic Web Components.

Features:

- Projects with estimated budgets in DH
- Expenses per project
- Automatic remaining/exceeded budget calculations
- Stats view
- Notes view
- Bottom mobile navigation
- LocalStorage only

## Run locally

Open `index.html` in a browser, or run a small static server:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Deploy

GitHub Pages is configured with GitHub Actions. Push to `main`, then open:

```text
https://khalidelyounssi.github.io/Budget-Manager/
```
