# Budget

Static mobile-style budget manager built with HTML, CSS, Vanilla JavaScript, and Ionic Web Components from CDN.

Features:

- Projects with estimated budgets in DH
- Expenses per project
- Automatic remaining/exceeded budget calculations
- Stats view
- Notes view
- Bottom mobile navigation
- LocalStorage only

## Structure

```text
index.html
css/style.css
js/app.js
```

## Run locally

Open `index.html` in a browser, or run a small static server:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Deploy

Use GitHub Pages with:

```text
Source: Deploy from a branch
Branch: main
Folder: /root
```

Final URL:

```text
https://khalidelyounssi.github.io/Budget/
```
